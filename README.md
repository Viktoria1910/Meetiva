//Meetiva

Web aplikacija za planiranje događaja koja povezuje korisnike s pružateljima 
usluga kao što su fotografi, glazbenici, catereri i dvorane za događaje.

Izrađena kao završni rad na Fakultetu elektrotehnike, računarstva i 
informacijskih tehnologija Osijek.

//Tehnologije

- React 18
- Vite
- Firebase (Authentication, Firestore)
- Tailwind CSS
- React Router

//Instalacija

///Koraci

1. Kloniraj repozitorij:
   git clone <https://github.com/Viktoria1910/Meetiva>

2. Instaliraj pakete:
   npm install

3. Kreiraj .env datoteku u korijenskom direktoriju i dodaj:
   VITE_FIREBASE_API_KEY=
   VITE_FIREBASE_AUTH_DOMAIN=
   VITE_FIREBASE_PROJECT_ID=
   VITE_FIREBASE_STORAGE_BUCKET=
   VITE_FIREBASE_MESSAGING_SENDER_ID=
   VITE_FIREBASE_APP_ID=

4. Pokreni aplikaciju:
   npm run dev

Aplikacija je dostupna na http://localhost:5173
